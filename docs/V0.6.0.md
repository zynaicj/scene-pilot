# V0.6.0 本地任务 API 与 SQLite

## 范围与启动

在 V0.5.0（`8843d79`）上增加 FastAPI、SQLite 任务状态和历史，保留现有 CLI、确认流程、地图证据和共享调用预算。
本版先完成可轮询的业务 API；不增加 SSE、自动重试、真实费用查询、多模态或前端。

```powershell
uv sync --locked
uv run scene-pilot-api
# 可选：uv run scene-pilot-api --port 8001 --database data/demo.sqlite3
```

默认地址为 `http://127.0.0.1:8000`，`/docs` 提供接口操作页面，`/openapi.json` 提供机器可读契约。
启动、健康检查、文档和查询均不构造模型或连接高德。`POST /tasks` 会尝试一次真实 Qwen 提取；确认后调用 `/start` 才会进入真实地图/规划流程，可能消耗额度。

仅适用于本机单用户和单进程，没有登录鉴权。CLI 固定监听 `127.0.0.1`；不要通过其他启动方式或代理直接暴露到公网。
第二个服务进程使用同一个数据库会拒绝启动，不会将第一个进程的任务错误标为中断。

## 接口约定

| 方法和路径 | 用途 | 关键输入 |
| --- | --- | --- |
| `GET /health` | 服务存活检查 | 无 |
| `POST /tasks` | 创建任务并提取草稿，返回 202 | `request`；可选 `Idempotency-Key` 请求头 |
| `GET /tasks` | 历史摘要，按新到旧排序 | `limit` 默认 20、最多 100；`offset` 默认 0 |
| `GET /tasks/{id}` | 需求、状态、版本、确认快照、出发位置选项 | 无 |
| `PATCH /tasks/{id}/brief` | 替换完整草稿 | `revision`、`brief` |
| `POST /tasks/{id}/confirm` | 明确接受当前草稿，返回 ready | `revision`、`accepted: true` |
| `POST /tasks/{id}/start` | 启动已确认任务，返回 202 | `revision` |
| `POST /tasks/{id}/origin` | 选择本次地图定位结果或明确跳过，返回 202 | `revision`，以及 `evidence_id` 或 `skip: true` |
| `POST /tasks/{id}/cancel` | 取消非终态任务，返回 202 | `revision` |
| `GET /tasks/{id}/result` | 取得终态结果 | 未结束时返回 409 |

创建使用同一个幂等键和完全相同的需求，会返回原任务，不再次调用模型；同键不同需求返回 409。
幂等键为 1–80 个字母、数字、下划线、点或连字符。没有键的每次提交均视为新任务。

所有修改操作必须使用最近读取的 `revision`。任务每次状态或内容变化都会加一；冲突返回 409，调用方应重新读取并展示当前信息。
确认接受的是已保存的整份草稿；`accepted` 只接受布尔值 `true`，不能使用字符串或数字。确认后不能修改，应新建任务。
`PATCH /brief` 是完整草稿替换，省略字段会恢复为空/默认值，因此编辑一个字段时应发送完整当前草稿。

用户界面或接入程序必须展示需求并取得真实用户接受，之后才能调用确认；不得让模型自动发送确认。
出发点同样必须展示地图返回的地址/坐标供用户选择，即使只有一个选项；只允许本任务提供的证据 ID，不能提交替换坐标或其他任务的位置。

## 手动操作示例

以下请求可在 `/docs` 逐步执行。每步读取返回的 `id` 和最新 `revision`；示例数字需替换成实际值。
执行提交和启动会使用外部服务，不应放入离线单元测试。

1. 创建任务：

```json
{"request":"杭州日系人像，从杭州东站西广场出发，单程驾车不超过40分钟"}
```

2. 查询详情直到 `awaiting_confirmation`，检查所有草稿字段；必要时先通过 `/brief` 修改。
3. 用户明确接受当前预览后，向 `/confirm` 发送：

```json
{"revision":2,"accepted":true}
```

4. 向 `/start` 发送确认响应的最新版本，例如 `{"revision":3}`。
5. 轮询详情。若为 `awaiting_origin`，展示 `origin_options`。用户选择后向 `/origin` 发送：

```json
{"revision":5,"evidence_id":"这里替换为用户选择的本次证据ID"}
```

若用户决定跳过，发送 `{"revision":5,"skip":true}`。跳过后可继续选景，但交通时长校验保持信息不足。
6. 进入终态后请求 `/result`。`result.recommendation` 是结构化推荐，`result.final_text` 是后端确定性生成的展示文字，`result.metrics` 是累计调用统计。

## 状态、恢复与预算

正常流程为 `extracting → awaiting_confirmation → ready → running → completed`；需要选出发点时，运行中临时进入 `awaiting_origin`。

| 终态 | 含义 |
| --- | --- |
| `completed` | 已完成有效方案提交，不保证每个候选满足全部约束 |
| `incomplete` | 未完成有效提交，返回已经取得的证据 |
| `budget_exhausted` | 模型、地图相关执行限制、图步骤或执行超时导致停止 |
| `failed` | 加载或规划异常；返回固定错误码，不返回供应商原始异常 |
| `cancelled` | 用户取消；取消在途异步工作，已发生调用仍可能计费 |
| `interrupted` | 服务停止、重启或等待出发点超时，不自动继续 |

默认最多 2 个活跃任务，提取、规划和等待出发点均占槽位，超出返回 503；待需求确认和待启动不占槽位。
出发位置选择最多等待 900 秒，超时中断，不自动选择或跳过。等待不消耗原有 180 秒执行期限。
提取最多等待 90 秒，尝试和 Token 计入同一任务的 12 次模型/40000 Token 停止阈值；地图总额度 8 次、搜索 2 次、天气 2 次、图步骤 40 均保持原值。
API 不绕过 `StreamObserver.arun`，不直接将图的自由文本作为最终结果。

重启后保留历史结果、待确认草稿、已确认待启动任务以及提取统计；当时正在提取、规划或等待位置的任务标为中断。
本版不持久化图检查点，所以中断的任务不能原地恢复，也不会自动重新调用服务；继续尝试须用户主动创建新任务。
取消/中断先写终态，工作者清理后可能继续保存已取得的部分结果；刚取消时 `result` 可暂时为空，晚到结果不会把任务变回完成。

## 数据、错误与边界

- SQLite 默认文件 `data/scene-pilot.sqlite3` 保存原始需求、完整草稿、确认快照、地图定位选项、用户选择、结果和调用统计。它包含用户输入与位置信息，应按私人项目数据保管；数据库、锁文件及事务附属文件均忽略提交。
- 模型/高德密钥从本地配置读取，不存入任务。安全 Trace 仅保存计数、状态和耗时，不记录请求正文、地图原始响应或密钥；接口不返回本地 Trace 路径。
- HTTP 错误使用 `error_code`：404 为任务不存在；409 为版本冲突、状态不允许或结果尚未就绪；422 为无效输入；413 为正文超出 64 KiB；503 为并发槽位已满。验证错误不回显提交内容。
- 原始需求最多 12000 字符，确认前还检查原文与草稿合计长度。无法自动提取时可人工填写，不自动重试；缺城市或风格不能确认。
- 数据库 schema 版本为 1，未知版本拒绝启动，不覆盖数据。SQLite 操作使用参数绑定；文件锁确保一个服务拥有数据库。
- 目前没有多用户隔离、鉴权、SSE、跨进程任务队列、历史删除接口或自动清理。HTTP 历史为简单分页；服务重启不会自动恢复运行中的 Agent。
- 坐标缺失仍保持未知；本版没有自动补造坐标或改变天气/太阳、路线的证据规则。许可、费用和现场效果仍需人工核实。

## 离线验收

全套 `python -m unittest discover -s tests -q`：145 项通过（原 115 项，新增 30 项）；`ruff check src/scene_pilot tests` 和 `uv sync --locked --offline` 通过。新增覆盖：

- 完整 HTTP 创建、编辑、确认、启动、选点、结果和历史；确认前不开始地图规划。
- 过期版本、重复启动、幂等键、跨任务选点、坐标注入、超量请求和安全错误输出。
- 立即取消、运行中取消、等待超时、服务停止和重新启动；没有自动重试收费工作。
- SQLite 持久化、事务回滚、参数绑定、未知 schema 和第二进程冲突保护。
- 生产适配器与真实 Deep Agents 图，使用离线模型/地图：一次检索返回三个候选，三条路线正常校验，最终提交和统计写入 SQLite。
- 提取用量触及总预算时，规划在地图调用前停止；失败、额度耗尽、取消和未提交均保留已有证据，屏蔽自由文本。
- 默认应用启动、健康检查和 OpenAPI 不构造外部服务客户端；模型配置异常后可人工补全草稿。

本轮没有执行真实 Qwen 或高德调用。真实模型遵循、地图响应差异和实际 HTTP 交互仍需后续少量受控验收。

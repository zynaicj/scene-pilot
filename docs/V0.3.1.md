## Windows / PyCharm 同步

当前工作区原有 `uv.lock` 镜像源修改未被覆盖。先查看 `git status`，如需保留该修改，可单独暂存后同步：

```powershell
git stash push -m "local uv.lock mirror settings" -- uv.lock
git fetch origin
git switch main
git pull --ff-only origin main
uv sync --locked --default-index https://pypi.org/simple
uv run --no-sync python -m unittest discover -s tests -v
```

保留 stash，勿直接覆盖新锁文件；如需继续使用镜像源，请单独核对变更。无需改动或复制覆盖 `.env`。

真实验收需要本地已有有效 Key，以下命令会使用服务额度：

```powershell
uv run --no-sync scene-pilot-check-model
uv run --no-sync scene-pilot
```

输入与旧基线相同的杭州日系、白裙淡妆、树林草地、三个候选地需求。观察：

- 主 Agent 有 `task` 委派，地图返回证据编号，最终调用 `finalize_recommendation`。
- 门票/许可/机位等显示待人工确认，材质与额外妆容不会进入用户原话字段。
- 正常运行 `status=completed`；预算不足或格式不支持时有明确不完整提示，不凑足虚构地点。
- Trace 最后一行比较 `elapsed_seconds`、`model_attempts`、`map_attempts`、`map_retries`、`cache_hits`、
  `input_tokens`、`output_tokens`、`usage_missing`、`raw_result_chars`、`compact_result_chars`。
- `model_calls` 是观测到的 AI 消息数，`model_attempts` 是实际发起的模型调用数；`tool_calls` 包含本地工具，
  `map_attempts` 才是地图上游尝试数（含重试）。字符压缩比例不等于 Token 节省比例。

## 保守限制

- 官方 MCP 的运行时 schema 如有变更，未支持的返回格式会失败关闭。需要用脱敏后的结构补充 fixture，不能让模型猜测原始文本含义。
- 本版未接入权威门票/开放时间/许可来源，相关字段始终为未知；`biz_ext.cost` 不等同门票。
- 40000 Token 是收到 usage 后阻止后续调用的阈值，已在途调用会造成超出；缺少 usage 时依靠调用次数/输出/时限控制。
- 同步流不能抢占阻塞调用；生产 MCP 运行使用异步 `arun`。取消不会撤销已发出的服务请求或已产生费用。
- AI 建议仍需摄影师判断；不声称已看过现场图片，不增加爬虫或付费视觉接口。
